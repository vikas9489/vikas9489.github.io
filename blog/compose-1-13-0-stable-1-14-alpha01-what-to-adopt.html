Compose 1.13.0 Stable and 1.14.0-alpha01: What Actually Changed, What Breaks, and What to Adopt First

Compose 1.13.0 is stable. The release landed on Nov 18, 2026 for Animation, Foundation, Material, Runtime and UI, with Material3 reaching 1.5.0, and the 1.14 cycle opened the same day with 1.14.0-alpha01 (Material3 1.6.0-alpha01). One caveat up front: the stable entries on the official release pages carry no itemized notes of their own and point to the release blog. The details below are therefore the cumulative changes from the 1.13 alpha, beta and rc notes, plus the 1.14.0-alpha01 notes, all fetched from the AndroidX release pages today.

1. Build requirements first

  • Kotlin 2.2 is required (from beta01).
  • compileSdk 37.1 for the Compose libraries (from alpha03). This is transitive, so apps and libraries consuming 1.13 need to update too.
  • lifecycle-runtime 2.10.0 (from beta01), needed for lifecycle lint checks with AGP 9.5.0-alpha04 and later.

2. Breaking changes since 1.12

  • Sliders: onValueChange is now required on Slider, VerticalSlider and RangeSlider. Hidden deprecated APIs were removed, including DraggableState on SliderState and the legacy Saver overloads; isVertical left SliderState.
  • Posture: Posture is replaced by WindowPosture (with WindowFold, FoldState, FoldOrientation, isTabletop, isFlat), and the Book posture is gone.
  • Blur: Modifier.blur's radius parameter and BlurScope.radius are renamed blurRadiusSpec.
  • Line height: LineHeight.Trim.isTrimFirstLineTop() and isTrimLastLineBottom() became the properties trimsFirstLineTop and trimsLastLineBottom.
  • Text obfuscation: TextObfuscationMode.Default is now System, and SecureTextField defaults to it.
  • Focus bounds: Modifier.onFocusedBoundsChanged is a no-op; use FocusTargetModifierNode.getFocusedRect().
  • Tests: Compose tests default to InputMode.Touch unless you pass ComposeUiTestConfig(inputMode = InputMode.Keyboard).

The slider change is the one most likely to fail a compile in a mature codebase, because the old call sites that omitted the callback were silently allowed before:

var volume by remember { mutableFloatStateOf(0.5f) }

Slider(
    value = volume,
    onValueChange = { volume = it },
    valueRange = 0f..1f
)

3. Text fields: the deprecation wave is real now

Across Foundation, UI and Material the value-plus-callback text field overloads are deprecated in favor of TextFieldState, and VisualTransformation is deprecated in favor of OutputTransformation. InputTransformation.maxLength is deprecated in favor of maxLengthTrim and maxLengthReject. The 1.14 alpha adds Material 3 TextField and OutlinedTextField to the deprecated list, plus TextFieldDefaults.DecorationBox in favor of the decorator APIs. Migrating now is cheaper than doing it under a wall of warnings:

@Composable
fun PriceField() {
    val state = rememberTextFieldState()

    BasicTextField(
        state = state,
        inputTransformation = InputTransformation.maxLength(8),
        outputTransformation = {
            if (length > 0) insert(0, "\u20B9")
        }
    )
}

Note that InputTransformation.maxLength is the form the 1.13 notes mark deprecated; swap it for maxLengthTrim or maxLengthReject depending on whether you want over-length input trimmed or refused. Also new in the cycle: TextFieldState now saves and restores its text style, and BasicTextField waits for window focus before starting the input session, so requesting focus in onCreate shows the keyboard (revert via ComposeFoundationFlags.isTextFieldWaitWindowFocusForInputSessionEnabled).

4. Rendering and layout changes that move pixels

  • Modifier.border has a new, more performant implementation (beta02) that also supports generic and polygon shapes via a runtime shader, and rc01 made it use the outline size. Each change has a ComposeFoundationFlags escape hatch, and screenshot tests may show minor differences.
  • Single-line height optimization is on by default (alpha03) and may shift some text metrics by a pixel.
  • VectorPainter shares ImageBitmap resources across composables drawing the same ImageVector; disable with ComposeUiFlags.isVectorDrawCacheSharingEnabled.
  • Lazy layouts: LazyLayoutCacheWindow is stable and you pass it to the composable. Providing it, or a LazyListPrefetchStrategy, through LazyListState is deprecated. A dynamic default cache window prefetches 10% to 50% of the viewport ahead, and staggered grids gained a cache window.

If you run screenshot tests, expect to re-record goldens for borders and text once, then review the diff rather than blindly accepting it.

5. New in 1.13 worth using

  • FlexBox and Grid APIs are stable, including Modifier.gridItem, Fr and GridTrackSize; FlexBox gained maxItemsInEachLine.
  • Modifier.blur { ... } supports progressive blurs such as gradients and custom shaders; LocalWindow and WindowInfo.isCrossWindowBlurEnabled help you fall back when cross-window blur is off.
  • LineHeightStyle.Mode.PerLine stops mixed font sizes in one paragraph from overlapping.
  • PolygonShape and MorphPolygonShape, with a top-level CornerRounding and in-place transform() and copy().
  • Testing: onDescendants(), captureToImage(timeoutMillis) and ComposeUiTestConfig.

6. What 1.14.0-alpha01 adds

Not for production, but it shows the direction:

  • Lighting: Modifier.illuminate, IlluminationScope and Modifier.lightAnchor, with DirectionalLight, SpotLight, PointLight and SurfaceMaterial.
  • Text drawing: DrawAnnotation for custom drawing behind or over AnnotatedString ranges, TextLayoutResult.getBoundingBoxesForRange and fillPathForRange, and BasicText overloads taking a styleProvider so dynamic styles can skip recomposition.
  • BorderRenderer draws borders identical to Modifier.border from any draw scope, such as a DrawModifierNode.
  • TextFieldState.onTextChanged callback, also available on rememberTextFieldState.
  • LazyGridItemScope.crossAxisCellCount, rememberStyleResolver(), and computedMediaQuery replacing the now-deprecated derivedMediaQuery.
  • Deprecations: the styleable() modifier with Style and StyleScope (use the styleResolver API), and MutableVector in favor of androidx.collection.MutableObjectList.

Bug fixes in the alpha worth noting: screen reader focus in LazyRow, LazyColumn and LazyGrid no longer resets, nested scroll jitter with AndroidView and AndroidFragment under a collapsing app bar is fixed behind AndroidComposeUiFlags.isNestedScrollInteropMeasureAndLayoutEnabled, and changing lazy grid item spans through state no longer throws.

7. Suggested upgrade order

  1. Move to Kotlin 2.2 and compileSdk 37.1 in a branch with no other changes.
  2. Fix the compile breaks: sliders, WindowPosture, blurRadiusSpec, line-height trim properties, TextObfuscationMode.System.
  3. Re-record screenshot goldens and review border and text diffs.
  4. Retire deprecated text field and cache window usages in a follow-up so the diff stays reviewable.
  5. Stay on stable for production; try 1.14 alphas only in a spike branch.

Takeaway: 1.13.0 is mostly a cleanup release. The risky parts are the toolchain bump and a handful of source-breaking renames, not new runtime behavior, and every pixel-affecting change shipped with a flag you can use to bisect a regression.
