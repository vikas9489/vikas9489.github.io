Android Dev Summit 2026 Keynote: BYO Agent, Android CLI Plugins, AppFunctions Beta and Googlebook

At Android Dev Summit on Oct 28, 2026, Matthew McCullough (VP, Product Management, Android Developer) published "Agentic and Flexible: A next era of Android development". It is the umbrella post: nothing in it is a deep dive, but it tells you which pieces are now stable, which are beta and which are still alpha. This is the version with the status of each item spelled out, plus the exact install commands from the Android CLI docs.

40+
ACP-compliant agents usable in Studio Rabbit 2
30+
Android skills across 20+ areas
3
official CLI plugins: Antigravity, Claude Code, Codex

1. Bring your own agent

Android Studio Rabbit 2 is stable. You can pick Claude Agent, Codex, Antigravity or any of over 40 ACP-compliant agents and use them with Studio's tooling. The post frames the whole summit around choice: you pick the model and the agent, Android supplies the tools.

2. Android CLI gets official agent plugins

The Android CLI is now installable as an official plugin for Antigravity, Claude Code and OpenAI's Codex. Each adds the android-cli skill so your agent can create projects, manage virtual devices, inspect live UI layouts, run Journeys and search the official Android Knowledge Base. From the docs:

# Claude Code
claude plugin marketplace add android/android-cli-plugin
claude plugin install android-cli@android-cli-plugin

# Codex
codex plugin marketplace add android/android-cli-plugin
codex plugin add android-cli@android-cli-plugin

# Antigravity
agy plugin install android-cli-plugin@antigravity-plugins-official

Inside a Claude Code session the same thing is /plugin marketplace add android/android-cli-plugin then /plugin install android-cli@android-cli-plugin. Antigravity gets the deeper integration: Compose Previews and a Device Hub appear alongside the conversation, for virtual and physical devices, local or remote.

New CLI capabilities listed in the post:

  • Device streaming and Compose previews. Remote real-device testing powered by Firebase, and agent-rendered Compose previews without an emulator or an APK deploy.
  • Profiling. Perfetto system traces for cold start latency, jank and background wakeups.
  • Analyze. Checks bundles and libraries for obfuscation, optimization and shrinking scores, using the same logic Google Play applies before upload.
  • Skills. 30+ skills spanning 20+ areas, such as permissions security, Glance widget layouts and Compose performance.

Why it matters: the plugin route means the same Android tooling follows you across agents, so switching from one coding agent to another no longer means rebuilding your Android setup.

3. Agentic experiences inside your app

  • Android intelligence system and Connected Apps. Prototype a Connected App that shares your services when Gemini is the system AI agent; sign up for the Connected Apps Platform preview to publish to production. You can build with Android MCP or remote MCP and register via the Google Connected Console preview program.
  • AppFunctions is now in beta. Android's tool-calling layer for exposing app functionality to on-device or system agents through Android MCP.
  • A2UI for Jetpack Compose, alpha. Agent replies rendered as interactive UI built from your own components rather than text.
  • ML Kit Agentic API on Gemini Nano 4, alpha. Extends the Prompt API; it auto-executes functions, saves conversation history, manages the orchestration loop and includes automatic guardrails.

4. Architecture, navigation and Compose

  • AppState, alpha. Compose's reactive model applied to the state layer, to preserve state across device configurations.
  • Navigation 3 1.2 is stable with deep links support and richer predictive back handling.
  • Compose 1.13 stable is upcoming, with Grid and Flexbox moving to stable and new features including Progressive Blur and Formatted Text.

5. Googlebook and foldables

With Googlebook arriving, the post pushes one codebase across phones and laptops. The Compose adaptive skill was updated: it can audit your Compose UI for keyboard shortcuts, custom pointer cursors, hover states and tooltips; it understands navigation and migrating layouts to Grid, FlexBox and mediaQuery; it handles end-to-end state management; and it refactors media and camera screens into tabletop layouts for foldable postures.

Next year Google Play will look closely at how apps and games run on foldables and provide more showcase opportunities. Details of any Play requirement are promised later this year, so nothing is mandated yet. Follow the Android adaptive quality guidelines now.

6. Android XR

XREAL AURA, described as the world's first wired XR glasses powered by Android XR, launched. Core Jetpack XR SDK libraries (SceneCore, ARCore for Jetpack XR, XR Runtime) are stable, as are the Android XR emulators in Studio (glasses, audio glasses, display glasses) and the Android XR Engine Hub for traces across Unity, Godot and Unreal. Geospatial APIs arrive in ARCore for Jetpack XR and Unity.

What to do this week

  • Install the Android CLI plugin for whichever agent you already use and let it run android analyze on your release bundle.
  • Try AppFunctions (beta) on one read-only feature, such as search, before exposing anything that writes.
  • Treat A2UI and the ML Kit Agentic API as experiments; both are alpha.
  • If you ship on Navigation 3, move to 1.2 for deep links and predictive back.
  • Run the Compose adaptive skill against your main screens to see what a desktop or foldable pass would change.

Sources: the Android Developers Blog post "Agentic and Flexible: A next era of Android development" (Oct 28, 2026) and the Android CLI agent plugins documentation on developer.android.com.
