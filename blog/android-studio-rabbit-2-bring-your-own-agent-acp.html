Android Studio Rabbit 2: Bring Your Own Agent via ACP, Plus AI Change Review

Android Studio Rabbit 2 is now stable, and the headline change is not another built-in model. It is that the IDE stops caring which agent you use. Through the open Agent Client Protocol (ACP), Studio hosts over 40 coding agents, hands them the same project tools the built-in Gemini agent gets, and adds a review flow for whatever they change. Here is what Google's October 28 posts actually say, and how to use it.

40+
ACP-compatible agents supported through BYOA
Rabbit 2
Stable Android Studio release with BYOA
/review
Command that starts an agentic change review

1. Bring Your Own Agent

BYOA is stable in Rabbit 2. The posts name Claude Agent, Codex from OpenAI, Junie and Google Antigravity as examples, and say any ACP-compliant agent can plug in. Setup is deliberately boring:

  1. Open the agent window and pick an agent, or go to Settings > Tools > AI > Agents.
  2. Authenticate with that agent's provider.
  3. Send your first prompt.

You can install several agents and switch between them. Logging in to Google Antigravity also gives access to the latest Gemini models at launch. The blog also notes you can use a specific provider to satisfy an enterprise agreement, though it gives no configuration details.

2. What the Agent Can See

The value of an IDE-hosted agent over a terminal one is context. Per the Android Developers Blog, agents running in Studio get access to:

  • Project structure, build and symbol resolution
  • Compose Preview rendering
  • The Android Emulator
  • Logcat
  • Android skills for larger tasks, such as migrating to AGP 9 or building adaptive layouts

What was not published: the posts do not define ACP's wire format, show a config file, or give an exact Studio build number beyond "Rabbit 2". Treat protocol-level details as something to check in the ACP spec and your agent's own docs.

3. Skills Manager

Android and Firebase agent skills come preinstalled, and a Skills Manager lets you curate them. Open it from the agent panel's three-dot menu (Manage Agent Skills), by typing @ in chat and choosing Manage skills, or via Settings > Tools > AI > Skills Manager. Installed skills are invoked with @ in the chat.

4. Change Review

Letting an agent edit forty files is easy; trusting the diff is the hard part. Rabbit 2 adds an agentic review:

  • Start from Agent Changes, Pending Commits or the Git Log, or run /review in the agent tool window.
  • The agent produces a list of Recommended Fixes for the changes.
  • After you address them, Create Walkthrough groups related diff chunks into logical themes instead of alphabetical file order.

The walkthrough is the part I would use most. Reviewing an AGP or Compose migration file-by-file hides the actual shape of the change; theme-grouped chunks surface it.

5. Around the IDE: Android CLI and Plugins

The companion tools post shows the same agent-first idea outside Studio. The official Android plugin installs into Claude Code and Codex like this (commands as published):

# Claude Code session
/plugin marketplace add android/android-cli-plugin
/plugin install android-cli@android-cli-plugin

# Codex
codex plugin marketplace add android/android-cli-plugin
codex plugin add android-cli@android-cli-plugin

New CLI commands called out there include android preview (render Compose Previews without an emulator or IDE; Google reports agents finishing UI tasks 77% faster with up to 3x fewer tokens in internal testing), android profiler leakcanary (heap analysis on your computer), android signals (Android vitals and Crashlytics data in the terminal) and android analyze (R8 effectiveness with JSON output for CI). The R8 Configuration Analyzer in AGP 9.3 runs with:

./gradlew :app:analyzeReleaseR8Config

Google also says there are now 30+ official Android skills across 20+ areas, installed with android skills add.

6. Also in Rabbit 2

  • Stable Android XR emulators for XR glasses, audio glasses and display glasses, with custom 360-degree photo or camera-feed environments and hardware LED indicators for mic and camera state.
  • LeakCanary agentic fixes in the Profiler's LeakCanary task, with narrative leak explanations and suggested code changes.
  • Gemini Enterprise (available since Rabbit 1): no retention of source code for training, audit logging, and admin policies over approved skills, agents and model endpoints.

Still Canary-only per the posts: the one-click AI > Migrate to Compose XML migration assistant, Fix with AI in the Profiler, and Lightbuild, an early-preview declarative YAML build configuration.

How I'd Use It

Pick one agent for a real task, such as a Views-to-Compose screen migration, and let it use the emulator and Logcat itself rather than pasting stack traces. Then run /review before committing, whichever agent wrote the code. Since the review is separate from the author, you can have a second agent critique the first one's work. That separation is the practical payoff of ACP: the IDE owns the tools and the review loop, and the model becomes a swappable part.

Sources: "Your favorite agents are now integrated in Android Studio" and "What's new in Android developer tools and performance at Android Dev Summit", both on the Android Developers Blog, October 28, 2026.
